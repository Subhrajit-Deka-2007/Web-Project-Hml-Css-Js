# Simon Game

A classic Simon memory game built with HTML, CSS, and JavaScript.

## How to Play
- Watch, memorize, and repeat the color sequence.
- Each new round adds a color.
- Mess up, and the game restarts.

## Features
- Color and sound animations
- Score tracking
- Responsive UI (mobile-friendly)
- Built without frameworks

## How To Run
Download this folder and open `index.html` in your browser.
